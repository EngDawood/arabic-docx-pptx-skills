# Arabic Word & PowerPoint (RTL)

[English](README.en.md)

بلوقن لـ Claude يجعل ملفات Word وPowerPoint العربية تخرج صحيحة الاتجاه من أول مرة: الجداول تبدأ من اليمين، ونقطة نهاية الجملة في مكانها، والترقيم مثل 1.2 يظهر بالترتيب العربي، والغلاف والفهرس جاهزان.

التصنيف: المستندات والكتابة الأكاديمية.

## المهارات

| المهارة | الاسم العربي | ماذا تفعل |
|---|---|---|
| `arabic-docx` | تحويل مستندات Claude إلى ورد (عربي RTL) | تبني ملف Word عربي (من اليمين لليسار) بنمط رسائل الماجستير السعودية: غلاف، فهرس محتويات يملؤه Word، ترقيم صفحات يبدأ من المتن، جداول ومعادلات Word حقيقية وصور. تعمل من مستند Claude Doc أو مباشرة بدون مستند. للمستندات الإنجليزية استخدم `english-docx`. |
| `english-docx` | ورد إنجليزي بسيط | تبني ملف Word إنجليزي بشكل عادي وبسيط: Arial أو Times New Roman، عناوين واضحة، جداول بسيطة، قوائم ومعادلات وصور. بدون غلاف أو فهرس إلا عند الطلب. APA أو غيره فقط إذا طلبته. |
| `arabic-pptx` | عروض بوربوينت عربية صحيحة الاتجاه | تبني عروض PowerPoint عربية صحيحة الاتجاه، وتصلح العروض التي خرجت فيها النقطة أو الترقيم في الجهة الخطأ، مع مرجع للأشكال والمخططات وSmartArt. |

## التثبيت

من دليل Claude للبلوقنات بعد إدراجه، أو في Claude Code:

```bash
/plugin marketplace add EngDawood/arabic-docx-pptx-skills
/plugin install arabic-docx-pptx@arabic-docx-pptx-skills
```

## أمثلة على الطلب

- "حوّل هذا المستند إلى ملف وورد" مع رابط Claude Doc.
- "اكتب لي تقرير التدريب الميداني كملف وورد مباشرة، مع غلاف وفهرس".
- "سوي لي عرض بوربوينت بالعربي عن الذكاء الاصطناعي في التعليم".
- "أصلح اتجاه هذا العرض" مع ملف pptx مرفق.

## ماذا يشغّل البلوقن

- البلوقن تعليمات ومراجع نصية فقط، بلا سكربتات. يكتب Claude في كل مرة برنامج Python قصيرا في مجلد العمل يبني ملف docx أو يضبط اتجاه ملف pptx حسب هذه المراجع، ثم يشغله في بيئة العمل نفسها.
- عند غياب المكتبات يثبّت Claude `python-docx` أو `lxml` عبر pip من PyPI.
- للمعاينة يحوّل الملف إلى PDF وصور محليا بـ LibreOffice وpdftoppm إن وجدت.
- عند التحويل من Claude Doc يقرأ المستند ويصدّره عبر موصل Claude Docs في حسابك.

البرامج التي يكتبها Claude لهذه المهام لا تتصل بالإنترنت ولا ترسل أي بيانات إلى أي جهة؛ تقرأ ملفاتك وتكتب الملف الناتج في البيئة نفسها.

## المتطلبات

Python 3 مع `python-docx` (للوورد) و`lxml` (للعروض). LibreOffice اختياري للمعاينة.
